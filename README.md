# Bus Management System

An Android-based Bus Management System developed in Java and XML. The application provides Ahmedabad bus route information by allowing users to select bus stops and view predefined route details.

## Technologies
- Java
- Android Studio
- XML
- AndroidX
- ConstraintLayout

## Project Structure
The Java source files in this repository were reconstructed from the project report. Keep the existing `app/src/main/res/` folder from your Android project with these files.

## Important
The route data in the application is manually defined in the Java source code and the route list is stored in `res/values/strings.xml`.
